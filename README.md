# 🩺 Disease Prediction from Patient Symptoms

A Machine Learning web application that predicts the most likely disease based on patient symptoms and provides a confidence score with a recommendation on whether the user should consult a doctor.

## 🚀 Features

- Predict disease from patient symptoms
- Confidence score for each prediction
- Doctor consultation recommendation
- Interactive Streamlit web interface
- Trained using Machine Learning algorithms

## 🛠 Tech Stack

- Python
- Pandas
- Scikit-learn
- XGBoost
- Streamlit

## 📂 Dataset

- UCI Heart Disease Dataset
- Pima Indians Diabetes Dataset
- *(or the dataset you actually used)*

## ⚙️ Installation

```bash
git clone https://github.com/Inayattulla/Disease_Predictor.git

cd Disease_Predictor

pip install -r requirements.txt

streamlit run app.py
```
